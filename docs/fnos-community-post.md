# Music Hub：一个容器管理音乐搜索、扫码登录与批量下载

我做了一个适合 NAS 的开源音乐工具 Music Hub，采用红白界面，界面和 Go 下载引擎已经整合进同一个 Docker 镜像，不需要再单独部署搜索/下载项目。

源码：https://github.com/io-aoleo/music-hub
镜像：ghcr.io/io-aoleo/music-hub:latest

功能：
- 搜索网易云、QQ、酷我、酷狗、咪咕，支持分页。
- 单曲下载、跨页多选、批量队列、失败重试。
- 网易云扫码登录，以及其他平台 Cookie 配置。
- 首次访问创建管理员，没有通用默认密码。
- 设置音乐目录、检查写权限、按计划补充曲库。

飞牛安装：
1. 在文件管理中创建项目目录，下载仓库的 compose.yaml。
2. 同目录创建 .env，填写自己的目录，例如：
   ENGINE_DOWNLOAD_PATH=/vol1/1000/music
   HUB_PORT=9985
3. 飞牛 Docker → Compose，导入该项目并启动。
4. 打开 http://飞牛地址:9985，创建账号，检查目录权限，再配置音乐平台登录。

已有音乐目录需要允许 UID 1000 读取和写入。网页中填写宿主机路径可以生成挂载配置；改变挂载后仍需重新创建容器。默认数据用 Docker 卷保存，升级不要执行 down -v。

镜像面向 Linux AMD64 / ARM64 构建，初始化、网页、引擎都在一个容器内，引擎仅监听容器内 127.0.0.1。项目不需要 privileged 和 Docker Socket。

下载依赖音乐平台可用性及账号权限，扫码不会额外授予会员权限。请仅下载和使用你有权访问的内容。
